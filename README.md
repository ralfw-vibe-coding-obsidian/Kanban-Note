# Kanban Note

Dieses Obsidian-Plugin zeigt einen gekennzeichneten Abschnitt einer Markdown-Notiz als Kanban-Board an.

Die Karten und ihre Daten bleiben vollständig in der jeweiligen Notiz gespeichert.

## Installation mit BRAT

Füge in BRAT dieses Repository hinzu:

`ralfw-vibe-coding-obsidian/Kanban-Note`

Releases enthalten `main.js`, `manifest.json` und `styles.css` als direkt installierbare Assets.
